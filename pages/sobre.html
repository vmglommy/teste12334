Por que GitHub Pages? (Site Estático)

Este portal foi desenvolvido com HTML5 e CSS3 como um site estático, hospedado gratuitamente via GitHub Pages.

Diferente de sistemas em PHP ou WordPress, ele não exige processamento no servidor nem banco de dados para exibir páginas informativas, garantindo carregamento rápido e versionamento via Git/GitHub.
